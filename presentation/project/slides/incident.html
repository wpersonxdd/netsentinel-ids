Opening an incident shows why it was raised: the features that are furthest from normal traffic. It shows how sure the model is, as a set of possible attack families with a ninety percent guarantee for every family, using conformal prediction. It suggests a first response. And the analyst's decision labels every flow of the incident at once, so the model can retrain on it. That closes the loop between the people and the model.
